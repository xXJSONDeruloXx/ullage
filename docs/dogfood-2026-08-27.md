* The default smoke fixture references TIS-100 (`370360`), which is not
  installed on this host. Running the smoke command with installed controls
  `3480` and `848350` is green; no depot was downloaded merely to satisfy a
  historical fixture.
* Steam's native 32-bit warning is informational on this macOS host. It did
  not prevent the mapped 32-bit titles from reaching their Windows processes.
* Steam Cloud warnings are allowed for this run by explicit user direction.
  No in-game save or account action is being performed; Cloud-native mapping
  remains a separate, deliberate test gate.
* The native Steam Helper target is the recorded UI target. The first restart
  did not bootstrap through the accessibility bridge, so the official native
  Steam bundle was reopened from the shell and the Helper target was
  reattached. Subsequent Play/Stop interactions were performed in Steam's
  normal library UI.
